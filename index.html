Bug Bounty

A bug bounty program is a deal offered by many websites, organizations and software developers by which individuals
can receive recognition and compensation for reporting bugs, especially those pertaining to
security exploits and
vulnerabilities.
These programs allow the
developers to discover and resolve bugs before the general public is aware of them, preventing
incidents of widespread abuse.
Bug bounty programs have been implemented by a large number of organizations, including Mozilla, Facebook, Yahoo!, Google, Reddit, Square, Microsoft, and the Internet bug bounty.
